# Pichangueo

Plataforma integral para la administración y reserva de canchas deportivas.

## Despliegue Rápido

Descarga y ejecuta el script correspondiente a tu sistema operativo:

- **Windows:** [desplegar.bat](https://github.com/pichangueo/.github/releases/download/v1.0.0/desplegar.bat) *(o doble clic)*
  ```cmd
  .\desplegar.bat
  ```

- **Linux / macOS:** [desplegar.sh](https://github.com/pichangueo/.github/releases/download/v1.0.0/desplegar.sh)
  ```bash
  chmod +x desplegar.sh && ./desplegar.sh
  ```

Una vez finalizado, accede a:
- **Web:** [http://localhost](http://localhost)
- **API:** [http://localhost/api/docs](http://localhost/api/docs)
